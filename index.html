1 / Product / Live in production

EESA.AI

A business runs its operations by asking.

Eesa connects to the systems a company already uses, builds the screens its team needs, and does the work: on the web, on iPhone and Android, and in WhatsApp.

Visit eesa.ai

Problem

A small business's day is spread over apps, spreadsheets and chat threads that do not talk to each other.

Product

One agent that reads those systems, builds a screen for each job and carries out the request, with a person's approval where it matters.

My part

The phone app, five add-ons, workflow and approval work in the backend, and the same screens on the web.

My work on Eesa, layer by layer

  • Phone app

    iPhone and Android

    Primary contributor to the app: chat, the Flow Board, and sharing a file to Eesa from any other app.

    Flutter / Dart / Swift

  • Add-ons

    Tools the agent can use

    Primary contributor to five add-ons that plug into the agent as tools and show up in chat, on the boards and on the team's phones.

    Node.js / MCP / PostgreSQL

  • Backend

    Workflows, roles, approvals

    Workflows that run on a schedule and wait for a person's answer, role-based access for add-ons, approval before the agent writes to an outside system, and the server-driven share page.

    Python / LangGraph

  • Web app

    The same screens in the browser

    The flows from the phone, built again for the web.

    Next.js / TypeScript

  • Attendance

    Staff clock in on site from their phone, and timesheets add themselves up.

  • Drive

  • Invoices

    Supplier invoices shared in from a phone, and sent on once approved.

  • Calls
